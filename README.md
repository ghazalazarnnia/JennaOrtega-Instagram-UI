# Jenna Ortega Instagram UI

A responsive Instagram-style profile page built with React Native, Expo, and TypeScript.

This project recreates an Instagram-inspired profile interface using Jenna Ortega as the profile example.

## Features

- Instagram-style profile layout
- Profile image
- Posts, followers, and following statistics
- Verified badge
- Follow and Message buttons
- Story highlights
- 6-image post grid
- Bottom navigation bar
- Notification alert icon
- Responsive mobile-style layout

## Technologies Used

- React Native
- Expo
- TypeScript
- Expo Vector Icons
- React Native StyleSheet
